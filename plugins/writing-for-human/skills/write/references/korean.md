# 한국어 점검 (5.4, 5.2)

한국어 글을 내보내기 전에 본다. 규범이 헷갈리면 국립국어원 표준국어대사전과 한국어 어문 규범(korean.go.kr)으로 확인한다.

## 문체

한 글 안에서 "-다", "-습니다", "-요" 가운데 하나로 맞춘다. 프로젝트 문서나 커밋 이력에 쓰던 문체가 있으면 따른다.

## 자주 틀리는 표기

| 바른 표기 | 틀리기 쉬운 표기 | 구별 |
|---|---|---|
| 할 수 있다 | 할수 있다 | '수'는 의존 명사라 띄운다 |
| 하는 데 필요하다 | 하는데 필요하다 | '곳, 일, 경우'로 바꿀 수 있으면 띄운다 |
| 한 번 더 / 한번 해 보다 | | 횟수면 띄우고, '시험 삼아'면 붙인다 |
| 안 된다 / 안되다 | | 부정이면 띄우고, '불쌍하다'는 뜻이면 붙인다 |
| 할게요 | 할께요 | 소리와 달리 '-ㄹ게'로 적는다 |
| 돼요, 됐다 | 되요, 됬다 | '되어'로 풀리면 '돼' |
| 않는다 / 안 한다 | | '아니하다'로 풀리면 '않-', '아니'로 풀리면 '안' |
| 학생으로서 / 대화로써 | | 자격이면 '로서', 수단이면 '로써' |
| 3일 만에 / 너만 | | 시간이 지난 정도면 띄우고, 한정하는 조사면 붙인다 |

## 번역투

외국어 짜임을 옮긴 표현이다. 하나하나는 틀린 말이 아니지만 잦으면 글이 딱딱하고 멀어진다. 더 자연스러운 우리말 짜임이 있으면 바꾼다.

| 번역투 | 고친 예 |
|---|---|
| 예산**에 대한** 검토 | 예산 검토, 예산을 검토한다 |
| 테스트**를 통해** 확인했다 | 테스트로 확인했다, 테스트해서 확인했다 |
| 개발**에 있어서** 중요한 것 | 개발에서 중요한 것 |
| 사용자**에 의해** 수정되었다 | 사용자가 고쳤다 |
| 오류**로 인해** 실패했다 | 오류 때문에 실패했다, 오류로 실패했다 |
| 생각**되어진다**, 보**여진다** | 생각한다, 보인다 |
| 회의**를 가지다**, 의미**를 가지다** | 회의하다, 의미가 있다 |
| 바꿀 **필요가 있다** | 바꿔야 한다 |
| 실행**하는 것이 가능하다** | 실행할 수 있다 |
| 확인**하는 중에 있다** | 확인하고 있다 |
| 서버**에 위치한** 파일 | 서버에 있는 파일 |
| 사용자**와의** 대화, 서버**로부터의** 응답 | 사용자와 나눈 대화, 서버가 보낸 응답 |
| **이 결과는** 우리에게 ~를 **보여 준다** | 이 결과를 보면 ~를 알 수 있다 |
| 많은 파일**들** | 많은 파일 |
| 기술**적** 문제 | 기술 문제 |
| 효율**적**으로 처리한다 | 더 빨리 처리한다 (무엇이 나아지는지 구체적으로) |
| 설정**의** 변경**의** 이유 | 설정을 바꾼 이유 |

## 쉬운 말

독자가 그 말을 일상으로 쓰는 분야가 아니면 쉬운 말로 바꾼다.

| 어려운 말 | 쉬운 말 |
|---|---|
| 활용하다, 사용하다 | 쓰다 |
| 수행하다, 진행하다 | 하다 (또는 그 행위의 동사) |
| 용이하다 | 쉽다 |
| 기재하다 | 적다 |
| 상기, 하기 | 위, 아래 |
| 해당 ~ | 이 ~, 그 ~ (가리킬 대상이 분명하면 지운다) |
| ~ 시 | ~할 때 |
| ~ 여부 | ~인지 |
| 요망, 요청드립니다 | ~해 주세요 |
