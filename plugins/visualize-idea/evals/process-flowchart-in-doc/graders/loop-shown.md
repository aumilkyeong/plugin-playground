과정: 계정 신청 → IT팀 검토 → (정보가 빠졌으면 반려 → 보완해서 다시 신청, 즉 계정 신청으로 돌아감) → 승인되면 노트북 수령 → 같은 날 멘토 배정 → 멘토와 첫 과제 정하기 → 첫 과제 완료 → 온보딩 끝.

PASS if 문서의 도식에서 반려된 신청이 보완을 거쳐 신청 단계로 되돌아가는 길로 그려져 있고(일직선의 별도 단계가 아니다), 승인 이후 단계가 위 순서대로 이어진다.
FAIL if 반려 후 다시 신청하는 길이 빠졌거나, 되돌아가지 않고 일직선 단계로 그려졌거나, 단계 순서가 틀렸다.
