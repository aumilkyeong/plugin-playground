이 문서는 신규 입사자 온보딩 과정을 도식으로 보여 준다.

PASS if 도식 바로 위의 제목이나 도식 바로 아래의 캡션 가운데 적어도 하나가, 이 과정에 대해 무언가를 주장하는 문장이다. 예: "반려되면 보완해 다시 신청해야 하고, 승인된 뒤에야 노트북과 멘토가 이어진다", "IT팀 승인이 온보딩의 유일한 관문이다".
FAIL if 제목과 캡션이 "온보딩 과정", "온보딩 흐름도", "신규 입사자 온보딩 다이어그램"처럼 주제 이름뿐이다.
