# 형식 고르기 (2.2, 3.1, 3.3, 3.4, 7.3)

형식은 관계를 주장한다. 나무는 "부모가 하나"라고, 2×2는 "두 축이 서로 독립"이라고, 고리는 "끝이 다시 처음이 된다"고 말한다. 그래서 형식은 내용의 관계가 그 주장과 맞을 때만 쓴다.

## 관계 유형과 형식

| 관계 | 알아보는 질문 | 형식 후보 | 형식이 하는 주장 |
|---|---|---|---|
| 순서·과정 | 단계가 정해진 순서로 이어지는가 | 흐름도, 단계 번호 목록 | 앞 단계가 끝나야 다음이 시작된다. 갈래는 판단 마름모로 보인다 |
| 인과 | A가 B를 일으키는가 | 원인과 결과를 잇는 화살표 도식, 원인이 많으면 피시본 | 화살표마다 근거가 있다 |
| 위계·포함 | 하나가 여럿으로 나뉘고 요소마다 부모가 하나인가 | 나무, 들여쓴 목록, 포함 상자 | 부모가 하나이고 형제끼리 겹치지 않는다 |
| 층·의존 | 위층이 아래층에 기대는가 | 층 쌓기 | 위는 바로 아래에 서고 층을 건너뛰지 않는다 |
| 연결망 | 요소 사이에 길이 여럿이고 정해진 꼭대기가 없는가 | 점과 선, 연결이 많으면 행렬 | 선이 있는 쌍만 관계가 있다 |
| 두 기준으로 나누기 | 두 축으로 나눠 볼 수 있는가 | 2×2, 행렬 | 두 축이 서로 독립이고 칸이 빠짐없다 |
| 여러 속성 비교 | 대상 여럿을 같은 속성으로 견주는가 | 표 | 그림보다 표가 낫다 |
| 겹침 | 집합이 서로 겹치는가 | 벤 다이어그램(집합 2~3개) | 겹친 부분에 실제로 속하는 것이 있다 |
| 순환 | 끝이 다시 처음으로 돌아오는가 | 고리 | 정말 되풀이된다. 빠져나가는 길이 있으면 그것도 그린다 |
| 대비·선택 | 둘 이상의 안이나 전후를 견주는가 | 같은 틀의 그림을 나란히 놓고 차이만 강조 | 틀이 같아야 차이가 보인다 |
| 시간 | 언제 무엇이 일어나는가 | 타임라인, 간트 | 간격이 시간에 비례한다. 아니면 밝힌다 |
| 주고받음 | 누가 누구에게 언제 무엇을 보내는가 | 시퀀스 다이어그램, 스윔레인 | 세로(또는 가로) 순서가 시간 순서다 |
| 상태 | 한 대상이 여러 상태를 오가는가 | 상태도 | 화살표마다 상태를 바꾸는 사건이 있다 |
| 공간 | 어디에 있는가 | 지도, 배치도 | 거리와 방향이 실제와 비례한다. 아니면 밝힌다 |

질문 종류로 빨리 고를 때: 누가·무엇이면 대상 그림, 얼마나면 차트, 어디서면 지도, 언제면 타임라인, 어떻게면 흐름도, 왜면 원인과 결과를 잇는 그림.

## 고르는 법

1. **뼈대 관계를 하나 정한다.** 관계가 여럿 겹치면 질문에 가장 중요한 하나를 뼈대로 두고, 나머지는 색, 점선, 레이블 같은 보조 표시나 다른 그림으로 돌린다.
2. **후보를 두세 개 떠올린다.** 위 표에서 그 관계의 형식 후보와, 다른 관계로 읽었을 때의 형식을 함께 본다. 흐름도나 마인드맵으로 바로 가지 않는다. 마인드맵은 위계만 있을 때 쓰고, 요소 사이에 순서나 인과가 있으면 쓰지 않는다.
3. **후보마다 형식이 하는 주장을 내용과 맞춰 본다.** 맞지 않으면 버린다. 예: 요소 하나가 부모 둘에 속하면 나무를 버리고 연결망이나 행렬로 간다.
4. **남은 후보 가운데 보는 사람이 질문에 가장 빨리 답하는 것을 고른다.** 보는 사람이 표준 표기법(시퀀스, 상태도, ERD, UML)을 알면 따르고, 모르면 상자, 화살표, 말로 그린다.
5. **맞는 형식이 없으면 섞는다.** 예: 층 쌓기 위에 요청이 지나가는 흐름을 겹친다.

## 은유 (3.4)

빙산, 깔때기, 다리, 산처럼 익숙한 사물의 꼴을 빌릴 때는 구조가 옮겨지는지 본다.

- 은유의 부분마다 아이디어의 어느 부분에 해당하는지 짝을 적는다. 짝이 없는 부분이 많으면 버린다.
- 은유가 몰래 들여오는 구조를 확인한다. 깔때기는 한 방향으로 흐르며 단계마다 줄어든다. 빙산은 보이는 것보다 숨은 것이 크다. 다리는 두 쪽을 잇는 길이 하나다. 나무는 뿌리 하나에서 갈라진다. 산은 정상이 하나다.
- 퍼즐 조각, 톱니바퀴, 전구처럼 흔해서 아무것도 더하지 않는 은유는 쓰지 않는다.
- 사용자가 은유를 직접 정하면(예: 세 층을 천지인으로) 그 은유에 맞춰 그리되, 맞지 않는 부분은 보고한다.

## 그림을 문장으로 다시 읽기 (7.3)

다 그린 그림을 표시 하나씩 문장으로 바꿔 읽고, 근거가 없으면 오른쪽 칸처럼 고친다.

| 표시 | 읽히는 주장 | 근거가 없으면 |
|---|---|---|
| 화살표 A→B | A가 B를 일으킨다, A가 B보다 앞선다, A에서 B로 무언가 간다 | 레이블로 뜻을 정한다. 상관만 있으면 화살촉 없는 선을 쓴다 |
| 닫힌 고리 | 끝없이 되풀이된다 | 열린 끝이나 빠져나가는 길을 그린다 |
| 깔끔한 상자 경계 | 서로 겹치지 않는다 | 겹쳐 그리거나 경계를 점선으로 한다 |
| 네 칸, 갈래가 다 찬 나무 | 이것이 전부다 | "기타" 칸이나 열린 끝을 둔다 |
| 같은 크기, 같은 줄 | 중요도와 수준이 같다 | 크기와 위치를 실제 비중에 맞춘다 |
| 위, 가운데 | 많다, 좋다, 중심이다 | 공간의 뜻과 내용의 뜻을 맞춘다 |
| 실선 | 정해졌다 | 추정, 가설, 계획은 점선이나 흐린 색, 물음표로 그린다 |
| 다듬어진 그림 자체 | 확정된 안이다 | 탐색 단계 그림은 제목에 "초안"이나 "가설"을 쓴다 |
