# 렌즈 색인

렌즈는 한 분야의 판단 기준을 담은 파일이다. 모두 이 파일과 같은 폴더에 있다. 질문에 걸리는 렌즈만 연다. 한 질문은 보통 1~3개에 걸린다.

## 프론트엔드·웹

| 렌즈 | 이런 질문이면 연다 |
|---|---|

| frontend-state.md | 이 상태를 URL·서버 캐시·컴포넌트 중 어디에 둘까, 저장할까 계산할까, 이 컴포넌트를 shared로 올릴까, 기능 모듈끼리 어떻게 의존할까, API 타입을 어디서 만들까 |

## 위험 찾기에서 나누는 법

무거운 설계를 위험 찾기로 볼 때만 렌즈를 나눠 최대 3번 동시에 부른다. 성능(`frontend-performance.md`), 접근성(`frontend-accessibility.md`), 보안(`frontend-security.md`)은 서로 다른 호출로 나누고, 렌더링·상태·신뢰성처럼 한 결정의 여러 면인 렌즈는 가까운 호출에 함께 싣는다. 보통 무게면 렌즈를 모두 한 호출에 싣는다.
