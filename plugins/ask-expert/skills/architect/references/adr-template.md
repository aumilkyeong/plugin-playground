# ADR 틀

프로젝트에 ADR 형식이 없을 때 쓴다. 파일 이름은 `docs/adr/NNNN-<결정을-짧게>.md`로 하고, 번호는 폴더의 마지막 번호에 1을 더한다. 사람이 읽는 문서이므로 `writing-for-human:write` skill이 있으면 그 절차로 쓴다.

```markdown
# <번호>. <정한 것을 한 문장으로>

- 상태: 채택 | 대체됨(<새 ADR 번호>)
- 날짜: <YYYY-MM-DD>
- 무게: one-way door | 여러 파일을 고쳐야 되돌림

## 결정

<무엇을 하기로 했는지 두세 문장. 읽은 사람이 바로 따를 수 있게.>

## 왜

<이 맥락에서 중요한 품질 속성과, 그래서 이 안을 고른 이유.>

## 검토한 대안

| 안 | 얻는 것 | 포기하는 것 |
|---|---|---|
| <채택한 안> | | |
| <다른 안> | | |

## 지금 할 것과 나중에 할 것

- 지금: <최소 범위>
- 나중: <확장과, 더할 때를 알리는 신호>

## 다시 볼 조건

<어떤 신호가 오면 이 결정을 다시 여는지.>

## 지킬 장치

<이 결정을 자동으로 지키는 검사: lint 규칙, 의존 규칙, 테스트, 예산.>
```
